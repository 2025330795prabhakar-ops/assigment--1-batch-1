# Linked List Management System

A Java console application for practicing singly and doubly linked-list operations.

## Files

- `LinkedListManagementSystem.java` - main menu and user interaction
- `SinglyLinkedList.java` - singly linked-list implementation
- `DoublyLinkedList.java` - doubly linked-list implementation

## Included Operations

- Insert at beginning, end, position, before a value, and after a value
- Delete from beginning, end, position, and by value
- Search and update
- Display, count, minimum, maximum, and middle element
- Reverse, ascending sort, and duplicate removal
- Forward and backward display for the doubly linked list
- Singly versus doubly linked-list comparison

For an even number of nodes, `findMiddleElement()` returns the second middle element.

## Compile and Run

```bash
javac *.java
java LinkedListManagementSystem
```
